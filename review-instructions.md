# Инструкция для AI-ревьюера

## Цель
Провести ревью кода `app.js` на соответствие принципам Clean Code.

## Границы
- Проверяй только `app.js`.
- Не редактируй файлы, только анализируй.
- Ищи: мёртвый код, дублирование логики, непонятные имена, комментарии-пересказы, длинные функции.

## Критерий готовности
Отчёт с тремя замечаниями. Для каждого: место в коде, проблема, условие проявления, способ проверки исправления.

## Формат вывода
Отчёт на русском языке в виде списка.
